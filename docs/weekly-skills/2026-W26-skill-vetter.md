# 本周一技：skill-vetter

## 为什么学这个

`skill-vetter` 用于在安装、更新或引入外部 skill 前做安全审查。它适合作为「每周一技」栏目的第一期：先建立安全判断习惯，再推荐更多自动化能力。

## 适合谁

- 需要从 SkillHub、ClawHub、GitHub 安装技能的用户
- 负责内部技能审核、导入、发布的管理员
- 希望让 agent 使用更多工具，但担心权限和安全风险的团队

## 10 分钟上手

1. 打开 `skill-vetter` 的 SkillHub 详情页。
2. 阅读 `SKILL.md`，确认它的触发场景和输出格式。
3. 找一个低风险候选 skill，要求 agent 先审查再给安装建议。
4. 检查输出里是否包含风险、权限、外部连接和建议结论。

## 30 分钟练习

选择一个你准备安装或更新的外部 skill，完成一次完整审查：

- 来源是否可信
- 是否要求敏感 token / 文件 / 网络权限
- 是否包含可疑脚本或二进制文件
- 是否适合直接安装、暂缓安装或进入人工复核

## 权限与风险

- `skill-vetter` 本身用于审查，不应绕过人工判断。
- 对需要密钥、账号、写权限、外部网络访问的 skill，应提高审查等级。
- 审查结论不是自动放行；高风险技能仍需管理员确认。

## 验收标准

完成本周学习后，你应该能做到：

- 说清楚什么时候必须先用 `skill-vetter`。
- 能拿到一份候选 skill 的风险摘要。
- 能根据审查结果给出安装、暂缓或人工复核建议。

## 常见问题

### 它会自动安装技能吗？

不会。它用于审查和建议，安装动作仍应由用户或管理员确认。

### 内部 SkillHub 上的技能还需要审查吗？

普通使用可以依赖平台已有安全标识；但外部导入、新发布、高权限或行为链路影响大的技能，仍建议复核。
